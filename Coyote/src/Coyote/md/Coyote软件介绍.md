# Coyote 软件介绍

## PEAK × DG-LAB 图形化联动工具

Coyote 是连接 **PEAK 游戏遥测与 DG-LAB 设备** 的桌面联动工具。PEAK 内的 BepInEx 插件负责采集状态，桌面端负责规则、网络、设备路由、多人绑定和图形化自定义规则。

---

# 1. 实时游戏状态

Coyote 可以读取并展示：

- 血量、体力、额外体力；
- 死亡、昏迷；
- 攀爬、接地、蹲下、跳跃；
- 速度、位置和运动信息；
- 当前手持物、口袋、背包；
- 最近使用 / 食用 / 消耗物品；
- Injury、Hunger、Cold、Poison 等异常状态；
- 场景、关卡与运行时扩展字段；
- 多人联机玩家遥测。

---

# 2. DG-LAB 控制

支持：

- DG-LAB App 扫码配对；
- A/B 通道独立控制；
- 内置和自定义波形；
- 有限持续时间和 `-1` 条件持续语义；
- 多设备管理；
- 多人玩家与设备绑定；
- 一键立即停止；
- 总输出开关。

强度数字表示协议等级，不代表实际 mA。

---

# 3. 官方内置规则

当前官方规则覆盖血量下降、死亡、昏迷、体力消耗、速度阈值、跳跃、攀爬、蹲下、物品、异常状态、恢复、区域、随机波形、强度渐升、百分比档位和瞬时变化加强等能力。

官方规则可以独立使用。图形规则也可以复用其中的“事件检测器”，但只复用检测能力，不代表图形规则属于官方规则系统。

---

# 4. 图形化自定义规则

用户不再需要编写 `.py` 自定义规则。新版使用类似 Shader Graph / Blueprint 的 **模块 + 端口 + 连线** 编辑方式：

```text
事件 / 数据
    ↓
比较 / AND / OR / NOT
    ↓
边沿 / 冷却
    ↓
强度 / 持续时间 / 波形 / 动态档位
    ↓
电击输出
```

规则数据保存到：

```text
Coyote/visual_rules.json
```

这是 JSON 图数据，不执行用户 Python 代码。

模块库包括：

- 当前软件已注册的规则事件；
- 遥测字段、状态百分比、物品匹配、字段变化、常量；
- 比较、AND / OR / NOT、边沿、冷却；
- A/B 强度、随机强度、强度渐升；
- A/B 持续时间和波形；
- 百分比档位、瞬时变化加强、随机波形；
- 电击输出；
- 禁用软件内置规则；
- 自定义死亡 / 昏迷保护模块；
- 备注。

详细操作见 `md/图形化规则使用说明.md`。

---

# 5. 官方规则与自定义规则完全分域

当前设计明确分为两个逻辑域。

## 官方规则域

负责官方规则页面中的规则，包括官方死亡、官方昏迷以及官方死亡/昏迷后的规则级保护逻辑。

## 自定义规则域

负责 `visual_rules.json` 中的图形规则。

自定义规则不会自动继承官方死亡保护、官方昏迷保护、官方死亡电击或官方昏迷电击，也不会因为存在自定义死亡/昏迷图就覆盖对应官方规则。

两套系统共享的只是 DG-LAB 连接、设备 slot、总输出开关、强度硬上限、主动立即停止/断开等底层基础设施。

---

# 6. “禁用软件内置规则”模块

把 **禁用软件内置规则** 放入任意已启用且校验通过的普通图即可全局生效，不需要连线。

生效后会关闭整个官方自动规则域：

- 普通官方规则不再输出；
- 官方死亡电击不触发；
- 官方昏迷电击不触发；
- 官方死亡/昏迷后的规则级清输出保护不执行。

图形规则仍可以复用现有事件检测器做 detector-only 检测，但检测结果只提供给自定义图，不恢复官方输出。

---

# 7. 自定义死亡 / 昏迷保护

图形编辑器提供：

- **未死亡保护（仅自定义）**；
- **未昏迷保护（仅自定义）**；
- **存活且清醒保护（仅自定义）**。

普通自定义规则默认不会因为角色死亡/昏迷而自动停止。只有用户把保护模块连接到对应输出，该输出才受这一条件限制。

---

# 8. 自定义死亡 / 昏迷专用图

自定义死亡和昏迷触发分别使用：

- **死亡（专用）**；
- **昏迷（专用）**。

两者必须建立在不同规则图中。特殊图只允许专用触发器、边沿/冷却、输出参数、电击输出和备注，不混入普通事件/遥测/物品/比较逻辑。

这里的“专用”只表示自定义图内部结构隔离，不表示其拥有或替代官方死亡/昏迷规则。

---

# 9. 多人联机

多人模式支持：

- 查看队友实时状态；
- 多个 DG-LAB App / Slot；
- 选择本地主设备；
- 玩家与设备会话级绑定；
- 远程玩家规则输出独立开关。

多人绑定默认不永久保存。

---

# 10. 网络模式

提供：

1. **直连**：本机 Bun Relay + 手机可到达的电脑地址；
2. **项目预设 WSS Relay**：用户主动选择项目预配置的加密 Relay；
3. **自定义 WSS Relay**：用户提供兼容的 `wss://` 地址。

直连失败不会自动切换到公网 Relay。

---

# 11. 当前源码结构

桌面端已经按职责重构：

```text
src/Coyote/
├─ main.py
├─ backend.py
├─ i18n.py
├─ update_checker.py
├─ Plugin/CoyotePlugin.cs
├─ Telemetry/MultiplayerTelemetry.cs
└─ coyote_app/
   ├─ bootstrap.py
   ├─ features/
   │  ├─ extended.py
   │  ├─ multiplayer.py
   │  ├─ network.py
   │  └─ reporting.py
   ├─ ui/qt.py
   └─ visual_rules/
      ├─ engine.py
      ├─ integration.py
      └─ policy.py
```

旧的 `extended_features.py`、`ui_qt.py`、`visual_rules.py` 等文件仅作为兼容导入别名，不再保存第二份实现。

`backend.py`、`i18n.py`、`update_checker.py` 等依赖稳定文件位置来计算配置/语言/更新路径，因此保留在根层，避免为了目录外观破坏便携版路径。

---

# 12. 安装和使用

1. 检测或安装 PEAK BepInEx；
2. 安装 / 更新 `Coyote.dll`；
3. 启动 Coyote 并连接 DG-LAB App；
4. 启动 PEAK；
5. 使用官方规则，或进入 **图形化规则** 创建节点图；
6. 确认逻辑和低强度测试无误后，再开启 **允许电击输出**。

---

# 13. 输出边界

- 图形规则仍受总输出开关和强度硬上限限制；
- `-1` 持续输出由有限片段续播实现；
- 设备断开、关闭总输出、程序退出或点击“立即停止”可以终止设备输出；
- 官方规则域和自定义规则域的死亡/昏迷策略互不暗中继承；
- 自定义图需要的死亡/昏迷保护由用户显式加入对应保护模块。

Coyote 是第三方项目，不是 PEAK、BepInEx 或 DG-LAB 官方产品。

# Coyote — PEAK × DG-LAB 联动工具

> 让 PEAK 游戏状态与 DG-LAB 设备联动，并支持图形化自定义规则、多人设备绑定和多种连接方式。

Coyote 是一个面向普通用户的 PEAK × DG-LAB 联动工具。你可以把游戏中的掉血、体力变化、跳跃、攀爬、速度、物品、异常状态、死亡、昏迷、进入区域等事件转换为自己配置的 DG-LAB 输出。

不需要自己写 Python。自定义规则已经改成 **模块 + 端口 + 连线** 的图形化编辑方式。

> [!IMPORTANT]
> 本项目是非官方社区项目，与 PEAK、DG-LAB、BepInEx 官方均无隶属或背书关系。首次使用请从低强度开始测试，并确保你随时可以停止输出或断开设备。

```text
Coyote_Windows_x64_Portable.zip
```

下载后解压即可使用，不需要自己编译源码。

## 第一次使用

推荐按照下面的顺序操作：

1. 解压便携版并启动 `Coyote.exe`；
2. 在软件中检测 PEAK 安装目录；
3. 按提示安装或修复 BepInEx；
4. 安装 / 更新 Coyote 的 PEAK 插件；
5. 启动 PEAK；
6. 确认软件已经收到游戏状态；
7. 连接 DG-LAB App 和设备；
8. 先使用较低强度进行手动测试；
9. 确认设备和通道正常后，再启用自动规则或图形化规则。

完整步骤见：

**`Coyote/src/Coyote/md/快速上手.md`**

# 主要功能

## PEAK 游戏状态联动

Coyote 可以根据游戏中的各种状态触发规则，例如：

- 血量下降；
- 血量恢复；
- 体力消耗；
- 体力恢复；
- 死亡；
- 昏迷；
- 跳跃；
- 攀爬；
- 蹲下；
- 移动速度；
- 手持物品；
- 背包物品；
- 食用 / 消耗物品；
- Injury、Hunger、Cold、Poison 等异常状态；
- 状态恢复；
- 进入指定区域；
- 在指定区域停留；
- 其他游戏遥测条件。

每条规则可以单独配置输出方式。

---

## DG-LAB 控制

支持：

- A / B 通道独立控制；
- 通道强度；
- 持续时间；
- 多种波形；
- 随机强度；
- 随机波形；
- 百分比档位；
- 瞬时变化加强；
- 强度渐升；
- 持续型输出；
- 总输出开关；
- 一键立即停止；
- 强度上限。

> 软件中显示的强度数值是设备协议等级，不等于实际电流值。

# 图形化自定义规则

新版已经取消“用户自己编写 Python 自定义规则”的使用方式。

现在可以直接在软件中通过图形模块创建规则，例如：

```text
速度高于设定值
      ↓
存活且清醒保护
      ↓
设置强度
      ↓
设置持续时间
      ↓
设置波形
      ↓
电击输出
```

也可以组合多个条件：

```text
速度高于 8 ─────┐
                 ├─ AND ─→ 电击输出
正在攀爬 ────────┘
```

或者：

```text
拿到指定物品
      ↓
冷却
      ↓
随机波形
      ↓
电击输出
```

### 图形规则可以使用的模块

包括但不限于：

- 游戏事件；
- 遥测字段；
- 状态百分比；
- 物品匹配；
- 字段变化；
- 常量；
- 大于 / 小于 / 等于等比较；
- AND / OR / NOT；
- 上升沿 / 持续条件；
- 冷却；
- 强度；
- 持续时间；
- 波形；
- 随机波形；
- 百分比档位；
- 瞬时变化加强；
- 自定义死亡 / 昏迷保护；
- 电击输出；
- 禁用软件内置规则。

# 官方规则和自定义规则

软件里有两套可以同时存在的规则：

### 软件内置规则

就是原本规则页面中的血量、体力、速度、跳跃、物品、状态、死亡、昏迷等规则。

### 图形化自定义规则

由用户自己通过模块和连线创建。

这两套规则互相独立。

如果两边都启用，并且条件同时满足，两边都可以分别触发。

---

## “禁用软件内置规则”有什么作用？

如果你希望完全由自己的图形规则接管，可以在一张启用的普通图中放入：

**禁用软件内置规则**

这个模块不需要连线。

启用后会关闭软件内置的自动规则，包括：

- 普通内置规则；
- 内置死亡规则；
- 内置昏迷规则；
- 内置死亡 / 昏迷后的规则级保护。

但是以下设备功能仍然有效：

- 总输出开关；
- 强度上限；
- 设备连接检查；
- 立即停止；
- 断开设备；
- 程序退出停止处理。

---

# 死亡 / 昏迷规则

自定义规则不会自动继承软件内置的死亡 / 昏迷保护。

如果你希望一条自定义规则在死亡或昏迷后停止，请自己加入：

- **未死亡保护（仅自定义）**；
- **未昏迷保护（仅自定义）**；
- **存活且清醒保护（仅自定义）**。

例如：

```text
速度高于阈值 ─────────────┐
                          ├─→ 电击输出
存活且清醒保护 ────────────┘
```

如果没有加入这些保护模块，自定义规则会按照它自己的条件判断是否继续生效。

死亡和昏迷也可以分别建立独立的自定义专用规则图。

---

# 多人联机

多人模式支持：

- 查看联机玩家状态；
- 同时识别多个 DG-LAB App / 设备；
- 选择自己的主设备；
- 把不同 PEAK 玩家绑定到不同设备；
- 为远程玩家单独控制自动输出开关。

玩家与设备的绑定默认只在当前会话中有效，不会永久保存。

---

# 网络连接方式

Coyote 提供三种使用方式。

## 1. 直连

适合电脑和手机可以直接互相访问的情况，例如：

- 同一个局域网；
- VPN；
- 可访问 IPv4 / IPv6；
- 自己配置的域名或网络环境。

这是优先推荐的方式。

## 2. 项目预设 WSS Relay

当电脑和手机不能直接互相访问时，可以主动选择项目提供的预设加密中继。

## 3. 自定义 WSS Relay

也可以连接自己部署的兼容 Relay。

公网中继需要使用：

```text
wss://
```

软件不会因为直连失败就自动偷偷切换到公网中继。

# 常见问题

## 游戏已经启动，但软件没有游戏数据

依次检查：

1. BepInEx 是否正确安装；
2. Coyote 的 PEAK 插件是否已经安装；
3. 游戏是否已经真正进入可控制角色状态；
4. 软件中的游戏连接状态是否正常；
5. 必要时重新安装 / 修复插件后重启游戏。

## DG-LAB 已连接，但规则不输出

检查：

- 总输出是否开启；
- 对应规则是否启用；
- 图形规则图是否启用并已经保存；
- 目标设备 / Slot 是否在线；
- 强度是否为 0；
- 冷却是否仍在生效；
- 条件是否真的满足；
- 自定义保护模块是否把当前状态拦截。

## 放了“禁用软件内置规则”以后，为什么原来的规则都不工作？

这是正常行为。这个模块就是用来让图形化自定义规则接管软件内置自动规则的。

## 自定义规则为什么死亡后还能运行？

因为自定义规则默认不自动继承内置死亡保护。

需要停止的话，请加入：

**存活且清醒保护（仅自定义）**

或对应的单独保护模块。

# 使用建议

首次使用建议：

1. 先不要开启自动规则；
2. 先确认设备连接正确；
3. 使用较低强度测试 A / B 通道；
4. 一次只开启一条简单规则；
5. 确认触发条件正确后，再增加复杂组合；
6. 熟悉“立即停止”和断开设备的位置；
7. 多人功能先完成玩家和设备绑定，再开启远程自动输出。

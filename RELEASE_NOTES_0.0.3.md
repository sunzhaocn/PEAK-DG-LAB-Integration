# Coyote 0.0.3

This release rebuilds the Windows x64 portable application from the current `main` source baseline.

## Included changes

- Latest PEAK telemetry/plugin source changes since 0.0.2.
- Latest network-mode and Qt UI changes since 0.0.2.
- GPL-3.0 license metadata normalized across the repository.
- Source-tree paths, third-party boundaries and version domains clarified.
- Automated Windows portable build and release validation added.

## Package

`Coyote_Windows_x64_Portable.zip`

The portable package contains the desktop application, the freshly built `Coyote.dll`, bundled DG-LAB WebSocket server resources and editable runtime resources required by the application.

## Notes

This is an unofficial community integration project and is not affiliated with PEAK, DG-LAB or BepInEx.

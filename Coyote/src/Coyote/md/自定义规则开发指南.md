# Coyote 自定义规则开发指南

## 1. 简介

Coyote 支持用户通过自定义规则扩展 PEAK 与 DG-LAB 的联动逻辑。

通过自定义规则，用户可以根据游戏内事件、角色状态变化、物品交互、环境条件等触发 DG-LAB 输出，实现更加个性化的互动体验。

自定义规则采用 Python 编写，无需修改 Coyote 核心代码即可扩展功能。

---

## 2. 规则文件位置

自定义规则目录：

```text
Coyote/
└─ custom_rules/
   └─ example_speed_climb.py
```

用户可以在该目录创建新的 Python 规则文件。

---

## 3. 基础规则结构

一个规则通常包含：

- 规则名称
- 触发条件
- 参数设置
- 输出逻辑

示例：

```python
RULE_NAME = "示例规则"

def check(data):
    """
    判断是否触发规则
    """
    return False


def execute(data):
    """
    执行触发后的操作
    """
    pass
```

---

## 4. 可使用的数据

Coyote 会向规则提供游戏遥测数据，包括：

### 玩家状态

例如：

- 当前生命值
- 当前体力
- 受伤状态
- 死亡状态
- 昏迷状态
- 攀爬状态

### 环境信息

例如：

- 当前地图
- 玩家坐标
- 区域状态

### 物品信息

例如：

- 当前手持物品
- 消耗物品事件
- 物品变化

---

## 5. DG-LAB 输出

规则触发后，可以调用 Coyote 的输出接口：

- 设置强度
- 设置波形
- 设置持续时间
- 执行渐变效果

例如：

```python
B.send_rule_output(
    rule_key,
    intensity=50,
    duration=1000
)
```

---

## 6. 开发建议

### 1. 避免高频触发

游戏遥测通常持续刷新。

建议：

- 增加触发间隔
- 避免每一帧执行输出
- 使用冷却时间

---

### 2. 设置合理默认状态

新规则默认应该关闭：

```python
enabled = False
```

用户确认后再开启。

---

### 3. 处理异常

规则运行过程中应避免影响主程序：

```python
try:
    execute()
except Exception:
    pass
```

---

## 7. 调试方法

运行 Coyote 后，可以通过：

- 软件日志窗口
- Python 控制台输出
- DG-LAB 连接状态

检查规则执行情况。

---

## 8. 发布规则

推荐结构：

```text
custom_rules/
├─ your_rule.py
└─ README.md
```

规则文件应包含：

- 功能说明
- 使用方法
- 参数说明
- 注意事项

---

## 9. 注意事项

自定义规则属于扩展功能。

开发过程中请注意：

- 不修改核心文件
- 不覆盖默认配置
- 避免无限循环
- 避免连续大量输出

合理设计规则可以获得稳定、安全的 PEAK × DG-LAB 联动体验。

# Coyote 软件介绍

## PEAK × DG-LAB 图形化联动工具

Coyote 是一个连接 **PEAK 游戏遥测系统与 DG-LAB 设备** 的桌面联动工具。

程序通过 BepInEx / Coyote.dll 读取 PEAK 的实时状态，再由桌面端完成规则判断、DG-LAB V4 通信、多人设备路由和输出控制。

---

# 1. 实时游戏状态

Coyote 可以读取并展示：

- 血量、体力、额外体力；
- 死亡、昏迷；
- 攀爬、接地、蹲下、跳跃；
- 速度、位置和运动信息；
- 当前手持物、口袋、背包；
- 最近使用 / 食用 / 消耗物品；
- Injury、Hunger、Cold、Poison 等异常状态；
- 场景、关卡与运行时扩展字段；
- 多人联机玩家遥测。

---

# 2. DG-LAB 控制

Coyote 支持：

- DG-LAB APP 扫码配对；
- A/B 通道独立控制；
- 多种内置和自定义波形；
- 有限持续时间和 `-1` 条件持续语义；
- 多设备管理；
- 多人玩家与设备绑定；
- 一键立即停止；
- 总输出开关。

强度数字表示 DG-LAB 协议等级，不代表实际 mA。

---

# 3. 内置规则

当前规则系统覆盖：

- 血量下降；
- 死亡；
- 昏迷；
- 体力消耗；
- 速度高于 / 低于阈值；
- 跳跃、开始攀爬、蹲下；
- 手持物与背包物品；
- 当前手持 / 背包状态；
- 全部异常状态；
- 食用 / 消耗物品；
- 血量、体力、异常状态恢复；
- 进入区域、区域停留；
- 随机波形；
- 受伤后强度渐升；
- 百分比档位；
- 瞬时大变化加强。

内置规则仍可单独使用，也可以作为图形化规则的事件检测来源。

---

# 4. 图形化自定义规则

自定义规则不再要求用户编写 `.py`。

新版规则编辑方式参考 Unity Shader Graph / Unreal Blueprint：

```text
事件 / 数据模块
      ↓
比较 / AND / OR / NOT
      ↓
边沿 / 冷却
      ↓
强度 / 持续时间 / 波形 / 动态档位
      ↓
电击输出
```

用户在软件内拖动模块并通过端口连线组成规则，规则保存到：

```text
Coyote/visual_rules.json
```

规则文件是普通 JSON，不执行用户代码，也不给规则文件系统、网络或命令执行权限。

### 图形模块覆盖

模块库会从运行时 `RULE_META` 动态生成“当前软件全部规则事件”，因此已注册的基础规则和 `extended_features.py` 扩展规则都可以直接作为事件模块使用。

另外提供：

- 遥测字段；
- 状态百分比；
- 物品匹配；
- 字段变化；
- 常量；
- 比较；
- AND / OR / NOT；
- 上升沿 / 持续；
- 冷却；
- A/B 强度与随机强度；
- A/B 持续时间；
- A/B 波形；
- 百分比档位；
- 瞬时变化加强；
- 随机波形；
- 电击输出；
- 禁用软件内置规则；
- 备注。

详细操作见 `md/图形化规则使用说明.md`。

---

# 5. “禁用软件内置规则”模块

在任意已启用且校验通过的普通规则图中放入：

```text
禁用软件内置规则
```

该模块存在即生效，不需要连线。

启用后：

- 普通内置规则不再直接向设备输出；
- 图形规则仍可订阅内置事件检测器；
- 图形规则订阅到但原本关闭的检测器，会在单个遥测处理周期内临时以“只检测、不输出”方式运行；
- 遥测处理结束后立即恢复用户原来的内置规则开关状态；
- 死亡 / 昏迷专用规则不受该模块误杀。

因此可以让一套节点图真正接管普通自动规则，而不是必须同时打开旧规则才能工作。

---

# 6. 死亡 / 昏迷专用规则域

死亡 / 昏迷不能使用普通规则事件节点伪装，必须使用：

- **死亡（专用）**；
- **昏迷（专用）**。

角色进入死亡或昏迷时，固定执行顺序为：

```text
清除之前的普通输出
        ↓
锁定全部普通规则 / 普通图
        ↓
检测死亡 / 昏迷边沿
        ↓
执行对应专用规则
```

专用图与普通图严格隔离：

- 死亡图和昏迷图必须分开；
- 专用图不能混入普通事件、遥测条件或“禁用软件内置规则”模块；
- 专用图只能包含专用触发、边沿/冷却、输出参数、电击输出和备注；
- 普通规则在角色恢复正常状态前保持锁定。

这样解决了旧逻辑中“死亡/昏迷规则自己被死亡/昏迷安全锁拦截”的冲突。

---

# 7. 多人联机

多人模式支持：

- 查看队友实时状态；
- 多个 DG-LAB APP / Slot；
- 选择本地主设备；
- 玩家与设备会话级绑定；
- 远程玩家规则输出独立开关。

多人绑定默认不永久保存。

---

# 8. 软件结构

主要组件：

```text
Coyote
│
├─ Coyote.dll
│  └─ PEAK 游戏数据采集插件
│
├─ backend.py
│  └─ 核心规则、DG-LAB 输出与配置
│
├─ ui_qt.py
│  └─ PySide6 桌面界面
│
├─ extended_features.py
│  └─ 恢复、区域、随机波形、渐升等扩展
│
├─ multiplayer_features.py
│  └─ 多人遥测与多设备路由
│
├─ visual_rules.py
│  └─ 图形化规则引擎与节点编辑器
│
├─ visual_rules_hardening.py
│  └─ 图形规则接管、专用规则隔离与执行边界
│
└─ dglab-websocket-server
   └─ DG-LAB V4 通信服务
```

---

# 9. 安装和使用

1. 在软件中检测或安装 PEAK BepInEx。
2. 安装 / 更新 `Coyote.dll`。
3. 启动 Coyote 并连接 DG-LAB APP。
4. 启动 PEAK。
5. 使用内置规则，或进入 **图形化规则** 创建节点图。
6. 确认逻辑后再开启左侧 **允许电击输出**。

---

# 10. 输出边界

- 自动规则默认应保持关闭，按需启用；
- 图形规则仍受总输出开关限制；
- 强度经过软件硬上限裁剪；
- `-1` 持续输出由有限片段续播实现；
- 设备断开、关闭总输出、程序退出或点击“立即停止”都可以终止输出；
- 普通节点不能获得死亡/昏迷专用输出权限。

Coyote 是第三方项目，不是 PEAK、BepInEx 或 DG-LAB 官方产品。

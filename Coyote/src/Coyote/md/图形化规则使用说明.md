# Coyote 图形化规则使用说明

## 目标

自定义规则不再要求用户编写 Python。新版使用**模块 + 端口 + 连线**的节点图，规则保存在 `Coyote/visual_rules.json`。

程序内部仍然是现有的 PySide6/Python 桌面程序，因此不额外引入 Unity 运行时；交互方式参考 Unity Shader Graph / Unreal Blueprint。

## 基本操作

1. 打开侧栏 **图形化规则**。
2. 在左侧模块库双击模块。
3. 在中间画布拖动模块排版。
4. 点击源模块右侧输出端口，再点击目标模块左侧输入端口完成连线。
5. 选中模块，在右侧修改属性后点击 **应用属性**。
6. 勾选 **启用当前图**。
7. 点击 **校验并保存**。

Delete / Backspace 删除选中的模块或连线；滚轮缩放画布。

## 模块覆盖

### 当前软件规则事件

“当前软件全部规则事件”由运行时 `B.RULE_META` 动态生成，因此现有规则及已安装扩展注册的规则会自动进入模块库，例如：

- 血量下降、体力消耗；
- 速度高于/低于阈值；
- 跳跃、开始攀爬、蹲下；
- 拿起物品、背包装入物品、当前手持/背包状态；
- Injury / Hunger / Cold / Poison 等异常状态；
- `extended_features.py` 注册的食用、恢复、区域规则。

死亡与昏迷不从普通事件模块创建，必须使用专用模块。

### 条件 / 数据模块

- **遥测字段**：读取 `hp`、`speed`、`climbing`、`position.x` 等遥测字段。
- **状态百分比**：读取异常状态百分比。
- **物品匹配**：判断手持、背包、口袋是否包含指定名称。
- **字段变化**：判断指定遥测字段本包是否发生变化。
- **比较**：支持 `>`、`>=`、`<`、`<=`、`==`、`!=`、`contains`。
- **AND / OR / NOT**：组合多个条件。
- **上升沿 / 持续**：把持续条件转换为边沿触发或持续条件。
- **冷却**：限制触发频率。

### 输出参数模块

- **强度**：A/B 基础强度、最大强度、随机强度范围。
- **持续时间**：A/B 独立持续时间，兼容 `-1` 持续语义。
- **波形**：A/B 独立波形。
- **百分比档位**：连接到输出 `modifier`，与 `value` 输入配合。
- **瞬时变化加强**：连接到输出 `modifier`，与 `delta` 输入配合。
- **随机波形**：连接到输出 `modifier`，从指定波形池随机选择。
- **电击输出**：最终动作模块。

## 禁用软件内置规则

把 **禁用软件内置规则** 模块放入任意**已启用**、通过校验的普通规则图即可生效，不需要连线。

生效后：

- 原 `B.rules` 自动规则仍可作为事件源被节点桥捕获，但不会直接向设备输出；
- 图形化规则继续运行；
- 死亡/昏迷专用规则域不受该模块屏蔽；
- 总输出开关、设备连接检查、强度硬上限、立即停止仍然有效。

## 死亡 / 昏迷冲突修复

旧逻辑存在实际冲突：代码先检测 `dead/passedOut` 并调用对应规则，但统一输出函数进入后又检查“当前死亡/昏迷”，因此死亡/昏迷规则本身也被安全锁拦截；随后规则处理器还会执行清除输出。

新版把它拆成两个执行域：

### 普通规则域

角色死亡或昏迷后：

- 普通内置规则停止；
- 普通图形规则停止；
- 手动/旧自定义脚本没有专用绕过入口；
- 已有普通输出先被清除。

### 死亡 / 昏迷专用规则域

只允许：

- **死亡（专用）**；
- **昏迷（专用）**。

进入状态时固定执行：

```text
清除之前的普通输出
        ↓
检测死亡 / 昏迷边沿
        ↓
执行对应专用规则图
        ↓
普通规则继续保持锁定
```

规则校验器强制要求：

- 一张特殊图最多一个专用触发器；
- 死亡图和昏迷图必须分开；
- 专用图不能混入其他事件触发器；
- 普通 `builtin_trigger` 不能伪装成 `dead` / `passedOut`。

这样“死亡/昏迷触发电击”和“死亡/昏迷后普通规则禁止电击”不再互相冲突。

## 规则文件格式

规则图保存为 JSON：

```json
{
  "format": "coyote-visual-rules-v1",
  "version": 1,
  "graphs": [
    {
      "id": "graph_xxx",
      "name": "规则名称",
      "enabled": false,
      "nodes": [],
      "links": []
    }
  ]
}
```

旧 `.py` 文件不会自动删除，便于人工迁移，但新版入口不再执行用户 Python 规则，也不会继续创建 Python 示例作为活动规则系统。

## 安全边界

- 左侧 **允许电击输出** 必须开启；
- 强度受 `GUI_INTENSITY_MAX` 限制；
- 波形必须来自当前 Coyote 波形库；
- 普通图在游戏角色死亡/昏迷时不执行；
- **立即停止**、关闭总输出、设备断开仍然可停止输出；
- 专用绕过只对 PEAK 游戏遥测里的 `dead/passedOut` 两个状态开放，不能被普通节点调用。
